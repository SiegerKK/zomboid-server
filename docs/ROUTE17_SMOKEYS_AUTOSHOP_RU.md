Основной корпус первого этажа: кухня `restaurantkitchen` (x10616..10620,
y9213..9219), бар (x10620..10625, y9213..9216), общий зал

и санузел. Второй этаж: общие комнаты, спальня, кухня и жилой сектор.
Основные сюжетные сцены добавляют предметы без замены существующей мебели;
две отдельные оконные сцены устанавливают баррикады только после

## 4. Как применять: по одной сцене, не весь пакет сразу

1. Обновить **существующий root-owned checkout** до согласованного
   проверенного коммита, после утверждения Draft PR #21. Это изменения
   сценариев и дополнительных серверных Lua API, не подмена радио PR #20.
2. RCON/сервер уже работали на `story_test` с открытой live-сессией;
   сначала проверить её актуальный `sudo pz story live-status story_test`.
   Ничего не восстанавливать и не переключать мир. Новые серверные
   Lua-обработчики требуют только согласованного контролируемого
   рестарта игрового контейнера при нуле игроков и cold checkpoint,
   если ещё не установлены. Для самих JSON-файлов рестарт не требуется.
3. Убедиться, что скачаны те же приватные снимки, что были переданы владельцем.
   Их SHA проверяет preflight. Запустить read-only проверку целиком:

```bash
python3 story/campaign/route17_scan_audit.py --site bar \
  --scan /var/tmp/bar-survey-101x101x5-20261017-17bbb716.json \
  smokeys_bar_01_public smokeys_bar_02_service smokeys_bar_03_upstairs \
  smokeys_bar_04_lived_in smokeys_bar_05_departure
python3 story/campaign/route17_scan_audit.py --site shop \
  --scan /var/tmp/workshop-survey-51x51x5-20261017-be026a6b.json \
  smokeys_shop_01_aftermath smokeys_shop_02_details smokeys_shop_03_infected
```

4. Дополнительно сверить точные индексы 10 важнейших шкафов/стеллажей
   с текущим save перед применением. Если изменились — остановиться.
5. Для Smokey's предварительно:

```bash
bash scripts/route17_smokeys.sh --scan /var/tmp/bar-survey-101x101x5-20261017-17bbb716.json --scene smokeys_bar_01_public
```

С разрешения владельца применить **ровно одну** сцену:

```bash
sudo bash scripts/route17_smokeys.sh --scan /var/tmp/bar-survey-101x101x5-20261017-17bbb716.json --scene smokeys_bar_01_public --apply
sudo pz story live-status story_test
```

Убедиться, что все action ID получили `applied` или `already`, не
`pending`/`error`. При pending дождаться загрузки клеток/персонажа.
Затем последовательно выбрать сцену 02, 03, 04, 05, меняя только `--scene`.
Не отправлять следующую сцену при незавершённой предыдущей.

6. Auto Shop, сначала документы и предметы 01/02:

```bash
sudo bash scripts/route17_autoshop.sh --scan /var/tmp/workshop-survey-51x51x5-20261017-be026a6b.json --scene smokeys_shop_01_aftermath --apply
sudo pz story live-status story_test
```

Проверив вторую сцену, активировать противников **до входа игроков в бокс,
после подтверждения безопасности и API/сетевого поведения**:

```bash
sudo bash scripts/route17_autoshop.sh --scan /var/tmp/workshop-survey-51x51x5-20261017-be026a6b.json --scene smokeys_shop_03_infected --apply --allow-infected
sudo pz story live-status story_test
```

Для учёта помеченных объектов `sudo pz story quest-status story_test
<scene_id>`. Каждая из 13 сцен имеет **отдельный** quest_id в modData, а
индивидуальные item/zombie токены записаны в `data/Lua/SiegerStoryQuestEvents.txt`.
При перемещении предметов и выгрузке зомби журнал не является полной
картой их новых координат.

**ОСТОРОЖНО:** `apply-live` меняет игру и не подразумевает отмену,
не переигрывать сцену под новым ID ради восстановления от ошибки.
После проверки сохранять текущий мир; бэкапы остаются контрольными точками.
Убедиться в доступности Story и наличии игроков/отсутствии игроков согласно
отдельному графику обслуживания. `road_home` не трогать.

## 5. Приёмка

- Базовые Python/Lua тесты и GitHub CI — не доказательство результата в мире.
- На клиенте проверить 10 отобранных записок Smokey's: 5 в
  смысловых контейнерах и 5 открыто, включая лист расписания радиопоста
  на кухне 2-го этажа. Отдельно проверить 4 страницы NORTHBOUND LEDGER.
  Протестировать `Base.SheetPaper2` на реальном клиенте Build 42.21.
- Подтвердить по зонам общественный зал, кухню, медпункт, архив, верхний
  этаж, эвакуационный след; существующая мебель и её функции сохранены.
- Проверить 4 записки мастерской и 17 обоснованных предметов, затем 10
  spawn-tagged заражённых: синхронизация, перезаход, смерти, отсутствие
  дубликатов. Не путать их с естественной популяцией.
- H.'s Notes и van glovebox — отдельный технический этап с vehicle API,
  не блокирующий оформление интерьеров.
- В финальном отчёте присвоить PASS/FAIL/BLOCKED и приложить
  `live-status`/`quest-status` вместе с хэшами снимков.
- Сервер в конце продолжает работать на `story_test`,
  без восстановления старого состояния.
