# Деплой из main: TLOU «Дорога домой» (Contabo, Build 42.21)

**Цель:** после работы Codex игроки должны иметь возможность подключиться к `62.171.140.149:16261` без общего игрового пароля. Мир TLOU отдельный, старый vanilla и все резервные копии сохраняются.

## Не перепутать Git и VPS

- GitHub `main` содержит **проект и шаблоны**. Ни один новый мир не возникает на VPS от `git pull` сам собой.
- Только Кодекс с реальным SSH-доступом может выкачать фактические Workshop-моды, сгенерировать полный Lua из закреплённого образа, установить/обновить Bash-менеджер и запустить игру.
- Не скачивать и не исполнять непроверенные сторонние .sh из Steam Workshop; код модов всё равно исполняется внутри игрового процесса — проверить версии/хеши и держать игру изолированной.
- Не перезапускать/останавливать действующую игру с игроками. До переключения согласовать maintenance, корректно сохранить и сделать cold backup, не `docker compose down -v`.
- Не выключать root SSH, не перезагружать Contabo без console/rescue. Ubuntu остаётся 24.04 LTS.
- Настройки SaaS/host Nginx не менять при развёртывании мира.

## 1. Аудит и проверка проекта

1. Прочитать `AGENTS.md`, `docs/WORLD_MANAGER_RU.md`, `docs/TLOU_WORLD_DESIGN_RU.md` и `docs/MODPACK_RU.md` уже из `main`.
2. Убедиться, что `/opt/zomboid-server` — root-owned checkout с `main`, и закреплённая версия игрового образа именно B42.21.0. Секретный `.env` не перезаписывать из шаблона.
3. Проверить изменения локально до установки:
   ```bash
   bash -n pz
   bash tests/smoke.sh
   bash tests/tlou_audit.sh
   python3 tests/test_generate_tlou_preset.py
   docker compose --env-file .env.example config --quiet
   ```
4. При любом fail — остановиться и исправить код через reviewed Git commit, не трогать production.

## 2. Полный mod snapshot, источник истины

- **Только одно TLOU:** SP/MP fork Workshop `3781448194`, Mod ID `TLOU_Infected_MP`, плюс Zomboid Forge `3776274080` и Starlit Library `3378285185`. Никакого `3776164832` на этом мире, никаких Bandits2/Creator.
- Проверить именно реальные `mod.info`, `sandbox-options.txt`, `media/lua` в read-only `/srv/zomboid/mod-snapshot-mp-test/content/108600/{3781448194,3776274080,3378285185}`.
- `sudo bash scripts/audit-tlou-snapshot.sh /srv/zomboid/mod-snapshot-mp-test` должен пройти; если snapshot отсутствует, безопасно скачать/сформировать **изолированно**, не используя live-мир.
- Для ZombieBuddy проверить установленную Linux agent-версию, не подменять Windows DLL.
- **Существенно:** Forge классифицирует игровую популяцию по весам. Убедиться, что ZF_Zomboid (стандартный тип) отключён либо вовсе не добавляется данной сборкой. Запретить `Zombies = None`, иначе не будет основы для заражённых. Если переключателя `ZomboidSpawn` нет, убедиться по точному `OnLoadZTypes` и runtime, что Forge не добавляет `ZF_Zomboid`. Если он есть — остановиться, не обещать 100% TLOU.
- Проверить `HideIndoors` и его фактическую работу (Stalker/Clicker) на dedicated multiplayer; это движение к зданиям, а не изменение базового количества внутри.
- Все выбранные типы и веса должны подтверждаться реальным `sandbox-options.txt` установленного MP-мода. При несовпадении имён — обновить generator/intent из фактических источников с ревью, а не выдумывать.

## 3. Сборка full SandboxVars из pinned Docker image

После аудита:
```bash
cd /opt/zomboid-server
sudo bash scripts/prepare-tlou-world.sh
```
Он считывает `PZ_IMAGE` только из локального root-only `.env`, запускает image `cat /defaults/default_SandboxVars.lua` без сети и вызывает `scripts/generate_tlou_preset.py`.

Результат — `config/presets/TLOU_November_12Months.lua` (полный Build 42 `SandboxVars = { ... }`). Генератор проверяет каждое имя/тип vanilla и Workshop-поля, диапазоны mod-options, отсутствие неизвестных ключей. Если ZomboidForge не содержит настройки обычного типа — по умолчанию **откажется** делать production-файл; опция `--allow-unverified-vanilla` допустима только на disposable мире до дополнительного runtime-аудита. Записать найденные фактические Mod IDs, file SHA-256 и результат аудита в документацию.

Проверить в собранном Lua: 30 ноября, DayLength=6 (3 часа), TimeSinceApo=13 (12 месяцев), холод, PvP=true через `tlou-coop.env`, 10× Strength/Fitness, 4× Mechanics, 5× Woodwork, GlobalToggle=false, AmmoLootNew=1.4, нет zombie respawn, низкая общая плотность, 560/330/110/0 веса TLOU. Убедиться, что сам Build 42 распознаёт все ключи при старте, а конфиг после запуска не был перезаписан по умолчанию.

## 4. Новый слот и первый реальный запуск

1. Если Bash-менеджер ещё не установлен, сначала выполнить `docs/WORLD_MANAGER_RU.md`, root-owned symlink `/usr/local/sbin/pz`, import legacy **копированием**, backup; `pz` smoke-тест на VPS.
2. Перед работой проверить RCON `players=0` и согласованное окно. Выключить только текущий игровой стек через `sudo pz stop`; оставить старый world slot в неприкосновенности.
3. Создать:
   ```bash
   sudo pz create road_home mp-test TLOU_November_12Months tlou-coop
   sudo pz start road_home
   sudo pz status
   ```
4. Если имя `road_home` уже существует — **не перезаписывать**, выбрать новое и согласовать. При ошибке старта вернуть предыдущий слот с сохранением всех файлов.
5. Проверить startup `SERVER STARTED`, новую карту, контейнер, mods loaded, Java heap 8192m / 12g limit, реальные UDP 16261/16262 и паузу при пустом сервере. RCON 27015/TCP не публиковать.
6. Проверить время/температуру, реальные игровые XP и лут. Для обычных/специальных заражённых нужен runtime список ZTypes и игровое наблюдение, **не только факт скачивания модов**.
7. Измерить эффективность в 10 домах против улиц и убедиться, что обычные зомби не доминируют. При отсутствии «опасных домов» объяснить ограничение, предложить отдельный проверенный серверный аддон под B42 и повторить тест, не изменять наугад Zomboid population.
8. Создать холодный backup нового мира и проверить восстановление в отдельном слоте. Не очищать старые backups. Offsite пока отсутствует — сообщить об этом.

## 5. Подключение и администрация

- Клиент должен использовать **ту же Build 42.21.0**, совместимые моды из Workshop и отдельные Java-компоненты ZombieBuddy, если нужны.
- Join via IP `62.171.140.149`, port `16261`, Steam Relay OFF для проверки прямого UDP, пустой **server password**.
- Новые игровые аккаунты `kyrylo`, `ihor` используют свои отдельные личные пароли. После первого входа kyrylo: `sudo pz admin grant kyrylo`; переподключиться для появления меню админа. Не передавать ADMIN_PASSWORD другим игрокам.
- Первый тест: оба входят, смотрят одинаковых infected (особенно Clicker), ездят в одном автомобиле, перезаходят и подтверждают сохранение. Без двух клиентов нельзя честно подтвердить MP-синхронизацию.

## Достоверный итог

Только реально выполненные действия отмечать `verified`. Если отсутствует окно SSH, Workshop item или ZF_Zomboid невозможно отключить — оставить стабильный работающий мир, ясно сообщить блокер. Ни GitHub, ни настройки не означают, что сервер автоматически готов.
