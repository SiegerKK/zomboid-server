# TLOU: концепция мира «Дорога домой» для двух игроков

Статус: черновик дизайна, НЕ готовый игровой Lua. Полный SandboxVars.lua нужно экспортировать из точно такой же Build 42.21.0, которая установлена на VPS, и проверять после загрузки. Не использовать старые Build 41 enums. Bandits/Creator остаются отключены, приоритет TLOU; оригинальная B42.20 и SP/MP версии TLOU не должны быть активны одновременно.

## Чувство игры

История двух людей через годы после коллапса. Дом имеет ценность, поездка за запасами рискованна, встреча с Clicker страшнее десяти обычных зомби. Не превращать игру в круглосуточный гринд и спринтерское мясо.

## Стартовые художественные ориентиры

- Место во времени: давно заброшенный мир, визуальное приближение к 10–20 годам спустя (ванильный генератор не умеет правдоподобно сделать 20 лет истории).
- Заражённые: приблизительно Normal по B42.21, при необходимости 0.65–0.85 множителя; в городах опаснее, в лесах можно укрыться.
- Respawn отключён, миграция работает; размер групп средний/небольшой. Очищенные дороги постепенно становятся полезными.
- Состав TLOU: runners — массовая угроза, stalkers — засадные, clickers — редкие и очень страшные, bloaters — исключительные; проценты только после проверки реальных настроек установленного мода.
- Еда Rare; медикаменты Rare/Very Rare; патроны и оружие Very Rare, но не None; инструменты Rare/Normal.
- Машины Low, состояние Low/Normal, бензин Low, урон столкновений Normal (во избежание усугубления рассинхрона).
- Нет восстановления лута в контейнерах; вода и электричество отключаются быстро или уже отсутствуют. Растительность, одежда и окружение старые.
- Длительность суток ~2 реальных часа; ночь Dark, не Pitch Black; больше дождливых дней, прохладная погода, умеренный туман.
- PvP отключён; PAUSE_EMPTY=true; без общего пароля подключения, личные учётные записи.
- XP примерно 1.5x, чтобы два игрока могли отыгрывать риск, а не 20 часов прокачки после смерти.
- Смерть персонажа не удаляет мир и общий дом — рекомендуемый кооперативный режим.

ВАЖНО: расхождения Build 42.20 / 42.21 в полях сложности, loot и XP означают, что все реальные числовые значения/секцию модов обязан проверить агент на установленном образе. В частности, первоначальный TLOU B42.20-порт имеет замечания по мультиплеерным Clicker/Bloater и текстовым названиям sandbox-опций; альтернативная SP/MP-редакция заявляет исправления, но требует тестирования двух живых клиентов.

## Как создать пресет в нашем едином репозитории

1. На остановленном vanilla-мире выполнить sudo pz export-preset original TLOU_Year20_Base. Полученный полный Lua создаётся из фактического серверного Build 42.21, не из случайной старой интернет-таблицы.
2. Скопировать в config/presets/TLOU_Year20.lua и настроить в полном файле только подтверждённые поля/значения, включая секции TLOU из реального mod snapshot. Проверить Lua и загрузку на disposable мире.
3. Команда создания после проверки модов: sudo pz create road_home mp-test TLOU_Year20 tlou-coop. Если MP-редакция ещё не принята, временно проверить правила с vanilla.
4. Снимки SandboxVars и серверных правил изолированы по world slot; новый Git-пресет не перезаписывает существующий мир.
5. Для прав администратора создать аккаунт обычным входом в игру, потом sudo pz admin grant kyrylo на выбранном мире.

Нужно обсудить две художественные оси: эпоха «первые месяцы» или «много лет спустя»; сложность «напряжённо, но справедливо» или «очень жестокий survival». До принятия не включать необратимые настройки.
