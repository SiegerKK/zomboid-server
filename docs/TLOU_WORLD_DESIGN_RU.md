# TLOU — «Дорога домой», конец ноября / 12 месяцев после коллапса

**Статус: согласованные требования + проверенные имена ВАНИЛЬНЫХ ключей; игровой полный Lua ещё НЕ собран из фактической Build 42.21.0 и не развёрнут.** Действующий мир не менять. Два клиента для игрового MP теста обязательны. Источник значений — `config/presets/TLOU_November_12Months.intent.tsv` и экспорт полного 42.21.0 SandboxVars с установленного сервера.

## Зафиксированные владельцем требования

| Параметр | Build 42 sandbox / правило сервера | Значение |
| --- | --- | --- |
| Календарная дата | `StartMonth` / `StartDay` | 11 / 30 (30 ноября) |
| Длительность суток | `DayLength` | 6 = **3 реальных часа** |
| Сколько времени после катастрофы | `TimeSinceApo` | 13 = **12 месяцев** (enum 1 означает 0 месяцев) |
| Климат | `Temperature` | 2 = Cold |
| Частота дождя | `Rain` | 4 = Rainy |
| PvP | per-world `PVP` | **true** |
| Пауза при нуле игроков | per-world `PAUSE_EMPTY` | true |
| Сила | `MultiplierConfig.Strength` | x10 |
| Фитнес | `MultiplierConfig.Fitness` | x10 |
| Механика | `MultiplierConfig.Mechanics` | x4 |
| Плотничество | `MultiplierConfig.Woodwork` | x5 |
| Global XP | `MultiplierConfig.Global` | x1 |
| Per-skill XP toggle | `MultiplierConfig.GlobalToggle` | **false**: иначе индивидуальные значения игнорируются |
| Боеприпасы | `AmmoLootNew` | 1.4 (в B42 0.6 — обычное значение, до повторного баланса) |
| Огнестрельное оружие | `RangedWeaponLootNew` | 1.0 |
| Loot respawn | `HoursForLootRespawn` | 0 (ничего не восстанавливается само) |

12 месяцев — **возраст мира для состояния растительности/порчи продуктов, не перемещение календаря**. В календаре будет 30 ноября. Он не обязательно сдвигает внутренний `daysSurvived` в TLOU-моде: его реализацию проверить.

## Плотность и поведение заражённых (главный дизайн)

**Цель:** улицы относительно пусты, внутри зданий чаще встречаются заражённые, столкновения близкие и смертельно опасные. Одного параметра `PopulationMultiplier` для этого НЕДОСТАТОЧНО — он снижает численность и внутри, и снаружи.

Начальный тест: `Distribution=1` Urban Focused, `ZombieConfig.PopulationMultiplier=0.30` (примерно вдвое ниже B42 Normal=0.65), `ZombieRespawn=4` None, `ZombieMigrate=true`, `RespawnHours=0`, `RespawnMultiplier=0`. При запуске проверить, что выбранная категория `Zombies` не перезаписывает произвольное значение населения. Не ставить внешний спавн ниже, чем внутренний, с помощью несуществующей sandbox-опции.

ПОВЕДЕНИЕ из **исходников автора** `SimKDT/The-Last-of-Us-Infected-B42` (42.1.0, НЕ наша SP/MP-редакция): реальны `TLOU_infected.HideIndoors=true`, `OnlyUnexplored=false`, `WanderAtNight=true`, `MaxDistanceToCheck=50`, `HideIndoorsUpdates=30`, а веса типов заданы `RunnerSpawnWeight`, `StalkerSpawnWeight`, `ClickerSpawnWeight`, `BloaterSpawnWeight`. `HideIndoors` переносит заражённых к ближайшим зданиям при подходящих условиях; **это не отдельный множитель создания заражённых внутри зданий**. Не вставлять имена этих опций в production, пока они не будут подтверждены в точной установленной сборке `TLOU_Infected_MP`.

Предложенный баланс типов **как дизайнерская цель, не утверждение о реальных mod enum/weights**:
- Runners: ~60 % от custom-infected
- Stalkers: ~30 % с включённым перемещением/укрытием внутри зданий, если MP fork поддерживает
- Clickers: ~10 %; редкие и опасные
- Bloaters: **0 % на старте** (для 12 месяцев по оригинальному лору слишком рано; включить позже через согласованное событие/новую версию мира)

У оригинального мода от drenindok/Zenith clicker начинается примерно с 330 суток (поэтапно до 550), bloater — с 1825 суток. У MP редакции автор не обещает возможность отсроченного появления; Workshop содержит запрос добавить именно эту функцию. Проверить код и не полагаться на `TimeSinceApo` для автоматического переноса расписания.

Если MP fork не содержит `HideIndoors` или она не работает на сервере, **остановиться и доложить**, а не притворяться, что мы добились желаемого. Возможные решения после теста — отдельный небольшой, серверный мод поведения/спавна, но это отдельное изменение, требующее MP теста.

## Ресурсы и выживание

Поднимаем `AmmoLootNew` до 1.4, при этом `RangedWeaponLootNew` лишь 1.0: на складах, в полицейских участках и некоторых домах патроны реально встречаются, но не в каждом ящике. Контейнерные шансы остаются привязаны к ванильной loot distribution, это **не гарантирует боезапас на каждой локации**. Для оружия по типам зданий при необходимости нужен отдельный loot distribution patch после игровых замеров.

Еда 0.7, консервы 0.8, медицина 0.7, холодная осень, вода/электричество уже должны быть отключены к возрасту мира (проверить generated world). Нормальная механика автомобилей и их урона при столкновениях, чтобы не усугублять сетевую синхронизацию.

## Как получить НАСТОЯЩУЮ конфигурацию

1. Не менять текущее `original` (или действующий production slot). Сделать копию vanilla/test мира, остановить и экспортировать **полный** `SiegerZomboid_SandboxVars.lua` из фактического образа Build 42.21.0; проверить `VERSION=6` и состав таблиц.
2. Проверить установленный snapshot, а не Steam-description: `bash scripts/audit-tlou-snapshot.sh /srv/zomboid/mod-snapshot-mp-test`. Найти `sandbox-options.txt`, `mod.info`, серверную обработку спавна/типов и названия mod-specific полей; зафиксировать IDs + SHA-256 конкретных файлов в отчёте (не коммитить сами чужие моды).
3. Применить все `config/presets/TLOU_November_12Months.intent.tsv` к копии Build 42.21.0 полного `SandboxVars.lua`. Проверить каждое имя, диапазон и структуру; при отсутствии ключа — ERROR, НЕ автоматически добавлять неизвестный ключ.
4. Параметры TLOU заполнить ТОЛЬКО по реально установленным `sandbox-options.txt` и Lua (MP edition `3781448194`, Forge patch `3776274080`, Starlit `3378285185`). Записать, какое поле отвечало за вес, этап заражения и укрытие внутри, если они существуют.
5. Сохранить готовый **полный** файл в `config/presets/TLOU_November_12Months.lua`; выполнить Lua syntax и точечные проверки на новые значения. `config/server-rules/tlou-coop.env` уже содержит `PVP=true`.
6. `sudo pz create road_home mp-test TLOU_November_12Months tlou-coop` — только после проверки mod snapshot и готового Lua. Тестировать на отдельном слоте, никакого `down -v`. После загрузки сравнить live `SandboxVars.lua` с preset и проверить, что опции не перезаписались default.
7. Два клиента: 15 минут на улице, десять входов в дома, совместный бой, автомобиль, rejoin/save; измерить indoor/outdoor разницу, распределение типов заражённых и доступность патронов. Только после этих тестов принять баланс.
