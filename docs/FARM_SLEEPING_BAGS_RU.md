# Спальники фермы: предмет и установленная мебель

В Build 42.21.0 `Base.SleepingBag_*` — Moveable с WorldObjectSprite.
`ground/add` создаёт переносимый предмет, а не развёрнутое спальное место.
Для новых запусков сцены II–IV используют существующий `kind=bed`:
две нативные части `camping_02`, без изменения свойств общих спрайтов.

| Этап | Вариант | Спрайты N: позиции сетки (0,0), (1,0) |
| --- | --- | --- |
| II | Cheap Blue | camping_02_48, camping_02_49 |
| II | Green | camping_02_16, camping_02_17 |
| III | Cheap Green | camping_02_40, camping_02_41 |
| IV | Blue Plaid | camping_02_8, camping_02_9 |
| IV | Camo | camping_02_32, camping_02_33 |
| IV | Green Plaid | camping_02_24, camping_02_25 |

Источник соответствий: штатный `media/scripts/generated/items/moveable.txt`
и `media/newtiledefinitions.tiles` фактической Build 42.21.0. Проверены
CustomItem, Facing=N, SpriteGridPos, ForceSingleItem и BedType=badBed.
Вторая часть находится в соседней клетке X+1. Обе клетки проверяются
обычным native preflight: существующий пол, спрайт с реальным BedType,
отсутствие неподходящих объектов и конфликтов с остальным планом.
Файлы игры, текстуры и извлечённый полный атлас не публикуются.

Поставки больше не добавляют соответствующие шесть inventory-предметов.
Все остальные предметы и явные объёмы жидкостей сохранены. Новые планы:
construction 2/10/80/217, stock 40/44/41/49,
inventory-items 137/195/307/466 плюс шесть мебельных спальных мест.

Уже применённые этапы не мигрируют автоматически. Нельзя повторять их
ради превращения старого предмета в мебель. Если I–II уже завершены
со старыми digest, для III–IV используется явный план с сохранением
точного определения выполненных зависимостей и обновлёнными III–IV.
Прежние журналы, предметы, сохранения и контрольные точки не удаляются.
Два старых спальника II в текущем story_test пока остаются предметами.

Дополнительно включено уже проверенное исправление поставки I:
нативная кухонная полка имеет вместимость10, а не50. Семь банок фасоли
остаются на полке; остальная её поставка перенесена в свободный
пищевой шкаф теплицы `(9267,7767,0)`. Регрессия проверяет реальные
ёмкости полок10 и15 вместо общего предположения50.

Проверки: компиляция всех четырёх этапов, непрерывные пары частей,
отсутствие выдачи спальников через batch, неизменность прочих количеств,
накопительные ограничения хранения, native construction/setup tests.
Развёрнутый спальник III проверяется также независимым AreaScan в игре.
Само наличие BedType не является доказательством успешного сна игрока,
корректного подбора всей пары или сохранения после рестарта: это
отдельная клиентская приёмка. Runtime и checksum-клиент не меняются.
