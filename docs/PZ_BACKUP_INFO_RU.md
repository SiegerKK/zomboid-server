# Ограниченная диагностика резервных копий

`sudo pz story backup-info` возвращает JSON размеров стандартного каталога
`/srv/zomboid/backups`: количество архивов и файлов, логический размер,
выделенное место с учётом hard links и распределение архивов по каталогам.
Символьные ссылки и специальные файлы пропускаются с явным счётчиком.

`sudo pz story backup-info --verify-latest story_test` дополнительно проверяет
последний завершённый manager-архив выбранного мира: SHA-256 против sidecar,
читаемость tar, количество записей и объём обычных файлов до сжатия.
Команда ничего не распаковывает, не восстанавливает и не изменяет.
Пути из командной строки и произвольные корневые каталоги не поддерживаются.
Повреждение или отсутствующая контрольная сумма завершают команду ошибкой.

Для codex-pz используется тот же разрешённый `pz-vps story backup-info`.
Новые sudo-разрешения и root SSH не нужны. Код устанавливается обычным
механизмом exact-commit deployment после CI и холодной копии.

Архивы могут содержать приватные настройки и данные игроков; сам JSON не
содержит содержимого файлов. Не публикуйте архивы. Проверка читаемости tar
не равнозначна проверке загрузки сохранения игрой. Сохраняйте контрольные
точки; восстановление требует отдельного разрешения владельца.
